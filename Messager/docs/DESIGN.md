# Messager V1.1 界面实现规范

设计依据：简洁的会话体验、桌面文件交互、现代简约、舒适密度。界面为原生 Qt Widgets，图标由 QPainter 绘制，无远程图片、网页容器或生成截图素材。

## 排版与交互

Windows 优先 Microsoft YaHei，回退 Segoe UI；Linux 使用 Noto Sans CJK SC。正文默认 14 px，可改为 13–17 px；页面标题 26–27、分区标题 17、辅助说明 11–13 px。

图标按钮有工具提示与无障碍名称；按钮、搜索框支持键盘焦点；正文为 PlainText，支持选择复制。窄窗口允许会话列表和消息各自滚动，次要页面放入滚动容器。

会话详情、登录表单均为按需打开。新消息与发送状态不会伪造读回执、安全状态或联系人在线状态。当前演示的未查看计数仅表示本地界面状态。

## 后续可完善

真实图片 / 视频预览、拖放文件、通知托盘、无障碍屏幕阅读器专项验收、虚拟化长消息列表和大规模数据性能，未纳入本版。主题控件采用标准文字选择，未实现主题缩略图。
V0.2 已将默认服务切换为真实 CipherChat；登录、身份、好友、群聊和文件均走原生业务层。真实未查看计数表示界面本地尚未打开会话，不代表对端已读。文件完成与签收分别按后端事件展示。传输中不暴露不存在的暂停命令。
