# 双人在线五子棋

应用广场（侧栏四宫格）中的“双人五子棋”支持好友对弈。双方都需要含五子棋功能的客户端版本。

1. 登录后打开“双人五子棋”，选择好友，点击“创建房间并邀请好友”。
2. 好友会收到普通加密聊天中的五子棋邀请卡片，点击“加入房间”进入对局。
3. 房主执黑先行，受邀好友执白。15×15 棋盘，连续五子及以上获胜，无禁手。
4. 点击棋盘交叉点落子；红点表示最后一手。对方回合或正在等待确认时不能落子。
5. 临时断开后重新登录，房间和棋谱从聊天记录恢复。同步受阻可点击“重新同步”，房主需要保持客户端在线处理受邀方的落子。
6. “退出 / 认输”结束当前房间；再来一局通过创建新房间重新邀请。邀请有效期为 24 小时。

## 同步与边界

- 不新增服务端端口或独立游戏服务。房主维护权威棋谱，通过现有好友私聊发送邀请、加入、落子请求、棋谱快照、退出和同步消息。
- 所有游戏消息经过现有 ChatService / CipherChat 业务线程、身份验证和加密传输。应用界面不直接操作密钥、数据库或网络。
- 房间固定两个参与者；校验邀请发送者和实际好友会话，只有指定好友可加入。落子由房主校验轮次、坐标、空位和终局，白方等待房主快照确认，不进行先落子后回滚。
- 快照逐手重放验证，拒绝非法坐标、重复占位、终局后继续落子、棋谱回退及伪装房主的消息。游戏不是面向恶意房主的竞技反作弊系统。
- 后台同步帧保留在既有聊天历史中，但不显示成气泡、不增加聊天未读、不产生普通消息通知；邀请保留可点击的卡片。旧客户端可能看见协议文本，需要更新后加入。
- 游戏不自动接受邀请、不向真实好友自动发消息。演示模式不伪装成在线对局。未升级好友不会凭空获得游戏页面。

## 验证

`messager_miniapps_tests` 覆盖四方向判胜、边界和非法棋谱、消息识别等；`messager_live_tests gomokuRoomsInviteAndPlay` 使用隔离 TLS 服务和两个真实 CipherChatService，验证好友建立、邀请卡片、点击加入、双方落子、断开后重登恢复、伪造房主拒绝、胜负同步、重新邀请和退出。

真实好友的邀请与对局不属于自动验收；测试不使用生产账号数据。

2026-10-20 最终结果：小程序检查 37 通过，界面回归 22 通过，完整真实后端套件 13 通过，均无失败。实际双客户端对局覆盖邀请、加入、9 手落子黑方获胜、重登恢复、伪造房主拒绝、重新邀请与认输。最新日志为 `evidence/gomoku-final-*-tests.txt`，五子棋截图位于 `evidence/gomoku-20261020-final/live/`；已检查邀请卡片、双方棋盘、暗色和彩铅共 5 张截图。
