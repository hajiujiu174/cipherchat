# NEXTALK 0.3.25.0

软件正式更名为 NEXTALK，沿用原来的紫色聊天图标。聊天、邮箱登录及九款小游戏继续保留。

全新安装请运行 setup.exe；便携包完整解压后运行 NEXTALK.exe。桌面和开始菜单入口使用 NEXTALK 名称与紫色图标。

更新后首次正常启动会将属于本安装目录的旧快捷方式迁移到 NEXTALK，并备份原入口。当前电脑的旧界面选择器入口单独迁移。正在运行的旧窗口保持运行，重新打开后使用新版。

内部兼容名 Messager、更新通道 messager、账号与设置目录继续保留，防止历史消息、便签和成绩丢失。Messager.exe 是兼容入口，与 NEXTALK.exe 内容相同。

TLS 与密码哈希继续保留，无端到端加密或用户私钥。更名发布不修改线上账号数据库。
