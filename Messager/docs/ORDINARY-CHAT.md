# 普通聊天与邮箱登录

新版 0.3.15.0 使用 ordinary-v1 通信模式。新消息、群消息、五子棋同步、文件元数据与文件块不再使用端到端加密、用户身份私钥、预共享密钥、身份指纹或双棘轮。TLS 证书校验、密码 PBKDF2/HMAC 验证、文件摘要与消息去重保留。文件统一通过 TLS 中转。Base64 是传输编码，不是加密。

登录页支持用户名或已绑定邮箱加密码。邮箱先由服务器识别为原用户名，随后使用原用户名对应的本机历史目录；不创建邮箱名的另一份身份。

登录页的“邮箱验证码登录”打开独立页面，只填写已绑定邮箱和六位验证码。服务器单独管理登录用途的验证码，与注册和重置密码用途隔离；保留现有验证码的十分钟有效期、重发间隔、尝试限制和成功消费后不可重放规则。验证码不作为密码保存。生产邮件沿用服务器现有 SMTP 配置。

本地旧快照仅通过只读兼容入口解开一次。迁移前使用 SQLite 备份 API 保留 `.before-ordinary.bak`，包含原状态，仅供回退；新快照不序列化身份密钥、信任记录、棘轮或文件密钥。旧本机文本历史保留，未完成的旧加密传输取消，需重新发送。

新版客户端明确拒绝尚未提供 ordinary-v1 的服务器。旧版客户端也无法使用新版服务器的登录流程，因此服务器和客户端必须同步发布。旧服务器的待投递密文没有被伪装为明文；`cipherchat/scripts/migrate-ordinary-chat.py` 提供停服后的备份与迁移，保留账号、密码哈希、邮箱、好友及群组数据，退役旧公钥/预共享密钥与旧待投递密文。

本次开发和测试使用隔离服务器、合成账号及本地邮件回调。用户明确授权后，2026-10-20 已同步上线阿里云 ordinary-v1 服务、新旧地址的两条更新通道、0.3.15.0 完整安装器，并切换现有桌面入口。账号、密码哈希、绑定邮箱、好友、群组、资料和动态按原始字节摘要核对保持一致；55 条旧待投递密文已备份后退役。未向真实邮箱发送测试验证码，真实收件尚待用户使用时确认。
