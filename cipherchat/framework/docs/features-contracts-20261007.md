## 更新下载补充修复

用户在另一台电脑观察到下载慢、停住后重开可继续。沿用现有 update_get 路由与 256 KiB 摘要分块，增加有界并行下载、每个连接独立请求标识、网络超时后重新验证 TLS 并有限重试。证书错误、非法响应和摘要失败不绕过验证。已验证缓存仍用于断点恢复，版本只在全部校验通过后激活。StageOptions 默认单并发以兼容既有调用；正式更新器显式使用四个固定下载线程。RemoteOptions 允许测试注入传输和短超时。界面增加暂停及继续下载、重连状态、无响应看门狗，作用仅限该窗口拥有的更新子进程。

## 登录恢复与工作台事件顺序

BusinessWorker 向 GUI 发布 Online 之前先发布该账号的完整 RestoredView，避免开放操作后又被登录快照覆盖。工作台由主窗口协调两套视图的最新编辑；嵌入 ChatBridge 通过主窗口提交命令，持久化回执仅在其状态仍等于最新编辑时应用，过期回执不回滚选择、草稿或固定项。独立桥继续直接使用自己的 worker。此调整不修改核心事件或磁盘格式。

更新器的四个固定线程只服务独立更新进程的块下载；账号、会话、存储和交付仍由唯一业务线程拥有，不增加业务线程池。
