# M8-03 精简账号与安全信息展示

状态：done

## 目标

移除主界面的常驻身份指纹区与聊天页核对按钮。账号页默认只显示用户名、密码与账号操作；地址、端口、证书、证书名称和数据目录放入默认收起的高级设置。验证信息按需在独立安全详情中查看；原 TLS、身份变化阻断与人工确认机制不变，不自动信任联系人。

## 范围与调用影响

允许修改 framework/gui/main_window.cpp、framework/tests/acceptance/gui_driver.cpp、framework/tests/acceptance/test_M4_04.cpp、framework/tasks.json、framework/README.md、README.md、docs/clean-ui-20260916.md、docs/remote-client-clean-ui-20260916.md、启动CipherChat.bat 及本任务卡和独立验收产物。

ownFingerprint 不再是主窗口常驻控件，仅在 ownIdentityDialog 中创建。inspectIdentity 移入高级设置。GUI 驱动通过真实高级设置/安全详情取得指纹，确认双方匹配后才接受身份，保持原核对语义。公共服务接口、密钥和数据格式不变。

## 验收

- 默认账号页无地址/证书/指纹；高级设置可展开和收起，原连接值保持。
- 登录前后截图及最小窗口视觉检查。
- 双 GUI 经默认隐藏连接配置完成注册、身份确认、私聊、文件和群聊，旧身份迁移/重登录与直连偏好回归通过。
- 发布包独立生成并 smoke 验证，一键启动更新，旧包保留。

## 结果

GUI 相关 3/3 回归通过（7.05 秒），公网原账号重登录、身份和会话保持及双向聊天通过。默认/展开/安全弹窗/最小窗口截图已检查；最终 r2 包38文件及正式程序启动通过。批处理指向新包，旧包和数据保留。详见 `../../docs/clean-ui-20260916.md`。

## 追加：隐藏证书配置（2026-09-16）

用户要求普通用户不再看到证书配置。移除高级设置中的证书路径、浏览按钮和证书主机名输入框，认证时直接沿用启动配置中的 CA 与预期主机名。命令行参数、TLS 校验、账号作用域及数据格式保持兼容；启动配置缺失时给出使用随附启动脚本的提示，不再要求用户填写不可见的字段。

沿用本卡允许文件范围，追加 `docs/certificate-ui-20260916.md` 和 `docs/remote-client-auto-cert-20260916.md` 及独立构建、测试、截图、发布证据。调整原 GUI 驱动以适配移除的控件，运行受影响 GUI 回归并检查展开设置的截图；另存发布包后更新一键启动入口。历史验收记录保留。
