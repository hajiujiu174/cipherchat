# M10-15 Codex 登录界面记住账号与密码

状态：done。前置：M10-14。用户要求在登录界面添加“记住账号”和“记住密码”复选框。

## 范围

根据用户最新要求，本轮只完成 Codex（Widgets）登录界面。提供两个可用鼠标和空格操作的复选框，默认未选。记住密码同时记住账号，取消记住账号也取消密码。仅成功登录后记住本次提交的账号和密码，下次打开填入登录框，仍须点击登录。失败的登录不覆盖已有正确记录；改变账号或服务器不自动带入另一对象的密码。

复用 PlatformSecretProtector 的 Windows DPAPI 保护保存密码，不存明文，不新增加密算法，不改变协议、账号数据库和业务线程。取消选项清除对应已保存内容，保存失败在界面反馈。Qt Rhine 源码保持本轮开始前的状态，保留旧包、课设报告和既有验收。

允许修改 framework/gui/login_preferences.*、framework/gui/main_window.cpp、framework/CMakeLists.txt、framework/tests/acceptance/CMakeLists.txt、framework/tests/ui/test_login_preferences.cpp、framework/tasks、framework/tasks.json、docs 及本轮独立验收和交付脚本与产物。

## 验收

验证两个选项的联动、取消后清除、重开后恢复、密码遮罩、成功才保存、错误不覆盖、账号和服务器隔离，以及本地文件不包含明文密码。实际 Codex 窗口鼠标和键盘验收，覆盖窄屏、主题与缩放；运行相关原有业务与导航测试，保持既有超时。另存新版本地运行包，独立解压验证 Codex 启动，再更新已有桌面快捷方式。
