# M8-01 混合文件传输：P2P 优先与 Relay 回退

状态：done（代码与本地直连、Relay 回退验收已完成；公网跨网络 P2P 尚未验证）

## 目标

- 中心服务器继续负责会话加密后的 `file_meta`、在线状态和 Relay 回退。
- 文件块与文件 ACK 在可达时通过一次性 token 认证的临时 TCP 直连发送。
- 直连失败、超时或中途断开时自动回到既有 16 块窗口、4 块批量落盘的 Relay 路径。
- 保留 CCF3、端到端加密、SHA-256、断点续传和崩溃恢复语义。

## 验收

- `M8-01` 验证 IPv4 loopback 直连、错误 token 拒绝和 envelope 队列交付。
- 框架完整构建通过；M7-01 等既有文件传输测试保持通过。
- 校园网隔离、NAT 或客户端防火墙导致直连失败时，Relay 仍是可用路径；公网 P2P 性能和端口策略需要真实双端后续验证。
