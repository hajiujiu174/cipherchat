# M8-02 聊天页集成文件传输

状态：done

## 目标与范围

将独立文件页合并至私聊页。发送文件默认使用当前联系人；该会话的文件进度、恢复、取消和已保存的直连偏好均在聊天页操作。取消独立文件收件人输入，切换联系人时按对端过滤文件记录，防止对错误会话操作。保留后台传输。

允许修改：framework/gui/main_window.cpp、framework/tests/acceptance/gui_driver.cpp、framework/tests/acceptance/test_M4_04.cpp、framework/tasks.json、README.md、framework/README.md、docs/chat-files-20260916.md、docs/remote-client-chat-files-20260916.md、启动CipherChat.bat；新增同名任务卡及独立构建/验收产物。服务、加密协议与存储格式不变。

## 调用影响

GUI 自动化由数字页号切换改为按页面名称切换；filePeer 控件移除，文件发送复用 chatPeer。fileTransfers 与 fileProgress 标识保留，新增按联系人筛选及选择保持。原 M4-04 和 M7-02 的驱动同步适配，M8-preferences 保持覆盖原偏好持久化。

## 验收

- 实际双 GUI 从聊天页发文件、收到文件并校验一致，期间能看到文本和进度；群聊仍可用。
- 切换联系人隐藏其他会话的文件，恢复/取消不会操作已隐藏行；进度刷新保留选中任务。
- 普通窗口及最小窗口截图检查无截断、遮挡。
- GUI 相关回归、偏好测试和任务审计通过。
- 另存新版发布包并 smoke 检查；一键启动脚本指向新包，旧包保留。

## 结果

GUI 相关 3/3 CTest 通过（9.24 秒），公网双 GUI 文件、聊天、群聊、联系人筛选与选中保持通过；默认/最小窗口已检查截图。38 文件新包 smoke 通过，一键启动脚本已更新。详细结果与历史驱动竞争修复见 `../../docs/chat-files-20260916.md`。
